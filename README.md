# Оптические волокна (Fiber Finder)

Приложение для Android и Windows: цвета трубок/волокон и расчёт потерь GPON.

**Скачать:** [последняя версия](https://github.com/ed2net/fiber-finder/releases/latest)
- `FiberFinder.apk` — телефон Android
- `FiberFinder-Windows.zip` — компьютер (распаковать, запустить `FiberFinder.exe`)

Код приложения — в папке `app/` (Flutter). Сборка автоматическая (GitHub Actions) при каждом изменении.
